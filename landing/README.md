# MOLIDO — 3D Landing Page

لندینگ‌پیج سه‌بعدی رسمی برای معرفی پلتفرم **MOLIDO Core**.

## ویژگی‌ها

- صحنه سه‌بعدی کامل با Three.js (هسته، حلقه‌ها، نودهای مداری، ذرات)
- افکت Bloom و نورپردازی نئون
- حرکت دوربین با موس
- طراحی کاملاً ریسپانسیو
- انیمیشن اسکرول (Reveal)
- زبان فارسی (RTL)
- رنگ‌بندی تیره + سیان نئون + بنفش

## نحوه اجرا

1. فایل `index.html` را در مرورگر باز کنید.
2. یا با یک سرور ساده:

```bash
# با Python
python -m http.server 8080

# با Node (اگر npx دارید)
npx serve .
```

سپس به آدرس `http://localhost:8080` بروید.

## نیازمندی‌ها

- مرورگر مدرن (Chrome, Edge, Firefox, Safari)
- اتصال اینترنت (برای بارگذاری فونت و Three.js از CDN)
